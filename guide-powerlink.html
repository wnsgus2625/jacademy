FREE GUIDE 02

네이버 파워링크 광고
등록 가이드

대행사 없이 내 손으로 등록하는 순서입니다. 화면 순서대로 따라오시면 됩니다.

PART 1

시작하기

1

네이버 광고주센터 접속하기

네이버 검색창에 '네이버 광고주센터'를 검색한 뒤, 검색 결과에 나오는 '네이버 통합 광고주센터'를 클릭해 접속합니다. PC 환경에서는 Ctrl 키를 누른 채 마우스 휠을 움직이면 화면을 확대·축소해서 볼 수 있습니다.

2

회원가입 하기

광고주센터 홈페이지 우측 상단의 '회원가입' 버튼을 클릭해 신규 회원으로 가입합니다.

3

파워링크 메뉴에서 새 캠페인 만들기

좌측 메뉴에서 '광고 관리'를 클릭한 뒤 '파워링크'를 선택합니다. 이어서 '새 캠페인' 버튼을 클릭합니다.

PART 2

캠페인과 광고그룹 만들기

4

캠페인 이름과 하루 예산 입력하기

캠페인 이름을 입력하고, 하루 예산을 입력합니다. 예산 기준을 잘 모르겠다면 우선 1만 원으로 입력한 뒤 '저장' 버튼을 클릭합니다.

5

생성된 캠페인 확인하기

캠페인이 생성되면 목록에 캠페인 이름이 나타납니다. 캠페인 이름을 클릭해 상세 화면으로 이동합니다.

6

새 광고그룹 만들기

캠페인 상세 화면에서 '광고그룹' 탭을 확인한 뒤 '새 광고그룹' 버튼을 클릭합니다.

7

광고그룹 이름 및 URL 설정하기

광고그룹 이름을 입력합니다. URL 항목에서는 'URL을 선택하세요'를 클릭한 뒤 기존에 등록된 URL이 없다면 '새로 만들기'를 선택합니다.

8

비즈채널 이름과 사이트 이름, URL 입력하기

비즈채널 이름은 나에게만 보이므로 구분하기 쉬운 이름으로 입력합니다. 사이트 이름에는 홍보 문구 없이 사이트 이름(상호)만 입력하고, URL 항목에는 등록하려는 링크 주소를 입력합니다.

9

기본 입찰가와 하루 예산 입력하기

광고 클릭 1회당 지불할 기본 입찰가를 입력합니다. 이어서 하루 예산을 입력하며, 모르겠다면 우선 1만 원으로 입력한 뒤 '저장' 버튼을 클릭합니다.

10

광고그룹 이름 클릭해 상세 화면 진입하기

광고그룹이 정상적으로 생성되면 목록에 광고그룹 이름이 나타납니다. 광고그룹 이름을 클릭하면 키워드를 등록할 수 있는 상세 화면으로 이동합니다.

11

광고그룹 생성 완료 후 키워드 등록 시작하기

광고그룹이 생성되면 '키워드' 탭이 표시됩니다. '새 키워드' 버튼을 클릭해 키워드 등록을 시작합니다.

PART 3

키워드와 소재 등록

12

키워드 추가하고 저장하기

왼쪽 입력창에 원하는 키워드를 직접 입력하거나, 오른쪽 '키워드 기준 연관 키워드' 목록에서 '추가' 버튼을 눌러 키워드를 선택합니다. 키워드 설정이 끝나면 '저장하고 계속하기' 버튼을 클릭합니다.

13

키워드 검토 상태 확인하기

파워링크는 키워드까지 검토가 끝나야 노출이 가능합니다. 상태에 '중지: 키워드 검토중'이라고 표시되면 정상적으로 검토가 진행되고 있는 것이며, 평균 1~3일 소요됩니다. 반려됐다면 반려 사유를 확인해 수정한 후 다시 등록해야 합니다.

14

소재 유형과 사이트 이름 설정하기

소재 탭에서 '+새 소재' 버튼을 클릭하면 소재 만들기 화면이 열립니다. 소재 유형은 처음 등록 시 '단일형 소재'로 선택해주세요. 이어서 사이트 이름 항목에 노출하고자 하는 사이트명을 입력합니다.

15

표시 URL과 연결 URL 입력하기

PC와 모바일 각각 표시 URL과 연결 URL을 입력합니다. 'https://'는 이미 입력되어 있으므로 그 이후 주소만 입력하면 됩니다. 별도 사이트가 없다면 플레이스 링크로 연결해도 됩니다.

16

제목과 설명 문구 입력하기

원하는 제목과 설명 문구를 입력합니다. 의료광고가 아니라면 심의필 번호 항목은 비워두고 진행합니다. 설명 문구에는 '최고', '최대', '최초'처럼 사실 확인이 어려운 표현은 반려될 수 있으니 사용하지 않아야 합니다.

17

키워드 삽입 기능 활용하기

'키워드삽입' 버튼을 클릭하면 소비자가 검색한 키워드를 제목과 설명에 자동으로 넣을 수 있습니다. 대체키워드 항목에는 글자 수 초과 시 대신 노출할 짧은 키워드를 입력해주세요.

18

키워드 삽입 결과 확인 후 저장하기

등록한 키워드와 대체 키워드가 제목·설명에 자연스럽게 반영되었는지 소재 미리보기에서 확인합니다. 확인이 끝나면 '저장' 버튼을 클릭해 소재 등록을 완료합니다.

19

소재 검토 상태 확인하기

소재까지 검토가 끝나야 노출이 가능합니다. 상태에 '중지: 소재 검토중'이라고 표시되면 정상적으로 검토가 진행되고 있는 것이며, 검토가 완료되면 화면을 캡처해 인증해 주세요. 비즈머니 잔액이 없을 경우 검수가 진행되지 않으므로 반드시 5천 원 정도 충전해주세요.

자주 하는 실수

비즈머니 잔액이 없으면 키워드·소재 검수가 모두 멈춥니다. 등록 후 반드시 5천 원 정도 충전해두세요. 또한 제목·설명에 '최고', '최대', '최초' 같은 표현을 쓰면 반려되니 피해야 하며, 의료업종이 아니라면 심의필 번호는 그냥 넘어가도 됩니다.
