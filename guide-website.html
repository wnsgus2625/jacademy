FREE GUIDE 03

클로드 디자인으로 내 홈페이지
만드는 프롬프트

광고를 돌리기 전에 손님이 도착할 곳이 필요합니다. 아래 프롬프트를 그대로 쓰면 내 가게에 맞는 홈페이지를 비용 없이 만들 수 있습니다.

사용 방법

1

아래 프롬프트 전체를 복사하세요

2

대괄호 안에 있는 부분을 내 정보로 바꾸세요

3

클로드 디자인에 통째로 붙여넣고 전송하면 완성된 홈페이지 코드를 받을 수 있습니다

4

받은 코드를 깃허브에 올리면 무료로 내 홈페이지 주소가 생깁니다 — 연결 방법은 다음 자료에서 알려드립니다

사진은 그냥 첨부하면 됩니다

복잡하게 링크를 만들 필요 없습니다. 프롬프트를 붙여넣는 창 아래 클립 모양 버튼을 눌러 내 컴퓨터나 휴대폰에 있는 사진을 그대로 올리면 됩니다. 사진을 보고 위치와 톤까지 맞춰줍니다.

—사진은 한 번에 두세 장까지만 올리세요 너무 많으면 화면이 산만해집니다
—올린 뒤 이 사진은 히어로 배경 이 사진은 프로필 처럼 어디에 쓸지 한 줄로 말해주면 됩니다
—사진이 아직 없다면 사진 없음 회색 박스로 자리만 비워둬 라고 적으면 나중에 바꿀 자리만 만들어줍니다
STEP 1

프롬프트 전문

홈페이지를 만들어줘. 기본은 한 페이지로 가지만 내용이 많거나 나눠서 보여주는 것이 낫다고 판단되면 여러 페이지로 만들어줘. 여러 페이지면 첫 화면을 index.html 로 하고 메뉴로 서로 이동할 수 있게 해줘. [기본 정보] - 브랜드명: [예: 제이아카데미] - 무엇을 파는지: [예: 네이버 플레이스·파워링크 직접 운영 줌 강의] - 가격: [예: 149,000원, 선착순 10명 한정] - 상담/구매 연결 링크: [예: 카카오 오픈채팅 링크] - 추가로 유도하고 싶은 채널: [예: 인스타그램 계정 링크] [타겟 고객] - 메인 타겟: [예: 이미 대행사에 돈을 내고 있지만 답답함을 느끼는 사람] - 보조 타겟: [예: 직접 해보려는데 막막한 사람 / 아직 고민 중인 사람] [핵심 메시지] - 가장 강조하고 싶은 한 문장(후킹 문구): [예: 광고비, 어디에 얼마나 쓰였는지 확인해보신 적 있으신가요?] - 신뢰를 줄 수 있는 근거(경력, 숫자, 실적 등): [예: 9년 운영, 200개 이상 계좌 데이터] - 강조하고 싶은 장점 3가지: [예: 비용 절감 / 직접 운영 가능 / 안전함] [디자인] - 톤앤매너: [예: 신뢰감 있고 차분한 느낌, 과하지 않게] - 메인 컬러: [예: 네이비 #0B1F3A, 골드 #C9A84C, 아이보리 배경] - 폰트: 한글은 Pretendard, 숫자·영문 라벨은 IBM Plex Mono 같은 모노스페이스 폰트를 포인트로 써줘 - 시그니처 요소 하나만 강하게 넣고, 나머지는 여백과 타이포로만 위계를 줘서 담백하게 만들어줘 (테두리 박스, 배지, 그라데이션 남발하지 말 것) [사진 — 넣고 싶을 때만 작성] - 사진 사용 여부: [예: 사용함 / 사용 안 함] - 넣고 싶은 위치: [예: 히어로 배경 1장, 운영자 소개 프로필 사진 1장 — 두세 곳 이하로만] - 사진은 이 대화에 파일로 첨부했어 [사진이 없으면: 없음 — 회색 박스로 자리만 비워둬] - 사진 톤: [예: 밝고 화사하게 / 어둡게 톤 다운해서 텍스트가 잘 보이게] [페이지 구성 — 한 페이지면 아래 순서대로 이어지게 하고 여러 페이지면 적당하게 묶어줘] 1. 헤더 — 로고 + 상담 신청 버튼 (스크롤해도 고정) 2. 히어로 — 후킹 문구 + 부연 설명 + 상담 신청 버튼 3. 공감 섹션 — 타겟 고객이 겪는 고민 2~3가지 4. 신뢰 섹션 — 경력/숫자 근거 5. 핵심 장점 3가지 6. 보조 타겟 안내 (간단하게) 7. 진행 방식/커리큘럼 단계별 소개 8. 가격 안내 + 상담 신청 버튼 9. 운영자(대표) 소개 10. 마지막 CTA — 상담 신청 버튼 + 다른 채널(인스타 등) 링크 11. 푸터 — 사업자 정보 (상호/대표자/사업자등록번호/주소/통신판매업신고번호), 환불 규정은 접었다 펼치는 형태로 12. 모바일에서 스크롤하면 하단에 작게 고정되는 상담 신청 버튼 [기술 조건] - 한 페이지라면 index.html 한 개로 만들고 여러 페이지라면 페이지당 html 파일로 나눠줘. 모든 파일은 같은 폴더에 넣고 상대경로로 연결해줘 - 모바일 화면 기준으로 먼저 예쁘게 나오도록 (모바일 우선) - 폰트는 구글 폰트나 CDN 링크로 불러와줘 - 사진을 안 쓴다면 이미지 없이 텍스트와 레이아웃만으로 완성해줘. 사진을 첨부했다면 그 사진을 코드에 바로 넣어줘 - 스크롤하면 섹션이 부드럽게 나타나는 정도의 가벼운 애니메이션만 넣어줘 완성되면 코드 전부를 파일로 주고 파일이 여러 개면 어떤 파일이 어떤 페이지인지도 알려줘.

완성된 코드를 받은 다음 여기는 이렇게 바꿔줘 이 부분이 너무 화려한데 차분하게 줄여줘 처럼 계속 대화하면서 다듬을 수 있습니다.

STEP 2

받은 코드를 무료 홈페이지 주소로 만들기

클로드 디자인이 준 코드는 아직 내 컴퓨터 안에만 있는 파일입니다. 이걸 인터넷 주소로 바꿔주는 무료 창고가 깃허브입니다. 서버도 도메인도 돈 한 푼 안 들고 컴퓨터를 켜두지 않아도 계속 열립니다. 어려운 프로그램은 설치하지 않습니다. 웹사이트에서 마우스로만 진행합니다.

먼저 알아둘 단어 세 개
—깃허브 내 파일을 올려두는 무료 창고 사이트입니다
—레포지토리 창고 안에 만드는 폴더 하나입니다. 줄여서 레포라고 부릅니다
—깃허브 페이지 그 폴더를 인터넷 주소로 열어주는 무료 기능입니다
1

코드를 파일로 저장하기

클로드 디자인이 준 코드를 전부 복사합니다. 윈도우는 메모장 맥은 텍스트 편집기를 열어 붙여넣고 저장할 때 파일 이름을 index.html 로 적습니다. 확장자가 .txt 로 붙지 않도록 파일 형식은 모든 파일을 고르세요. 파일을 여러 개 받았다면 알려준 이름 그대로 같은 폴더에 저장하세요. 첫 화면은 반드시 index.html 이어야 합니다.

2

깃허브 가입하기

github.com 에 접속해 Sign up 을 누르고 이메일 비밀번호 아이디를 정합니다. 이때 정한 아이디가 내 홈페이지 주소에 그대로 들어가니 상호나 브랜드에 가까운 영문으로 짧게 만드세요. 가입 후 메일로 온 인증 번호를 넣으면 끝입니다. 요금제는 무료를 고르면 됩니다.

3

폴더 하나 만들기

오른쪽 위 더하기 버튼에서 New repository 를 누릅니다. Repository name 칸에 원하는 폴더 이름을 영문으로 적습니다. 예를 들어 homepage 라고 적으면 나중에 주소가 그렇게 만들어집니다. 그 아래에서 Public 을 선택하고 Create repository 를 누릅니다.

Public 은 코드가 공개된다는 뜻입니다. 홈페이지는 어차피 누구나 보는 것이니 그대로 두면 됩니다. 무료 주소를 쓰려면 Public 이어야 합니다.
4

파일 올리기

방금 만든 폴더 화면에서 uploading an existing file 이라는 파란 글씨를 누릅니다. 아까 저장한 index.html 파일을 화면 안으로 끌어다 놓고 아래 초록색 Commit changes 버튼을 누르면 올라갑니다. 커밋은 저장을 확정한다는 뜻입니다.

5

주소를 켜기

폴더 화면 위쪽 Settings 를 누르고 왼쪽 목록에서 Pages 를 찾습니다. Branch 라고 적힌 칸에서 None 을 main 으로 바꾸고 옆의 Save 를 누릅니다. 이 한 번의 선택이 내 폴더를 홈페이지로 바꿔주는 스위치입니다.

6

1분 뒤 내 주소 확인하기

같은 Pages 화면을 잠시 뒤 새로 고치면 주소가 나타납니다. 규칙은 항상 같습니다.

https://내아이디.github.io/폴더이름/

이 주소를 그대로 명함이나 플레이스 파워링크 광고에 넣으면 됩니다. 처음 한두 번은 화면이 비어 보일 수 있으니 2분 정도 기다린 뒤 다시 열어보세요.

내용을 고치고 싶을 때

깃허브에서 index.html 파일을 누르고 연필 모양 아이콘을 눌러 글자를 바꾸고 Commit changes 를 누르면 됩니다. 크게 바꾸고 싶을 때는 클로드 디자인에 다시 부탁해 새 코드를 받고 같은 방법으로 파일을 덮어쓰면 됩니다. 저장하고 1분쯤 뒤 홈페이지에 반영됩니다.

막힐 때 확인할 것
—화면이 하얗게만 나온다 파일 이름이 index.html 인지 확인하세요
—404 라고 나온다 주소 맨 뒤 슬래시까지 그대로 넣었는지 확인하고 2분 기다려보세요
—Pages 메뉴가 안 보인다 폴더가 Private 으로 만들어졌을 수 있습니다 Settings 아래쪽에서 Public 으로 바꾸세요
STEP 3 유료

주소를 내가 원하는 이름으로 바꾸기

여기까지는 전부 무료입니다. 다만 주소에 github.io 가 들어가는 게 아쉬우면 내 상호로 된 주소를 쓸 수 있습니다. 이 주소만은 돈을 내고 사야 합니다. 홈페이지 자체는 계속 무료로 열립니다.

—가격은 1년에 대략 1만원에서 2만원대입니다. .com 이 가장 흔하고 .kr 이나 .co.kr 도 많이 씁니다
—1년마다 다시 결제해야 합니다 갱신을 놓치면 주소가 사라지니 자동 결제를 걸어두세요
—가비아 후이즈 같은 국내 업체나 클라우드플레어에서 살 수 있습니다 국내 업체가 한국어 상담이 편합니다
1
주소 사기

가비아 같은 사이트에서 원하는 이름을 검색해 남아 있으면 결제합니다. 이미 누가 쓰고 있으면 다른 이름을 찾으세요.

2
깃허브에 내 주소를 알려주기

깃허브 폴더의 Settings 에서 Pages 로 들어가 Custom domain 칸에 방금 산 주소를 적고 Save 를 누릅니다.

3
주소 산 곳에서 연결 설정하기

주소를 산 사이트의 DNS 관리 화면에서 아래 줄들을 그대로 추가합니다. A 로 시작하는 네 줄의 숫자는 깃허브가 정해둔 공용 주소로 누구나 동일하게 적으면 됩니다. 하나만 적어도 연결은 되지만 네 개를 모두 넣는 것이 정석이고 더 안정적입니다. CNAME 줄의 내아이디 부분만 내 깃허브 아이디로 바꿔 주세요.

유형 CNAME · 이름 www · 값 내아이디.github.io 유형 A · 이름 @ · 값 185.199.108.153 유형 A · 이름 @ · 값 185.199.109.153 유형 A · 이름 @ · 값 185.199.110.153 유형 A · 이름 @ · 값 185.199.111.153

화면마다 칸 이름이 조금씩 다릅니다. 헷갈리면 고객센터에 깃허브 페이지에 연결하려 한다고 말하면 대신 넣어줍니다.

4
기다리고 자물쇠 켜기

연결에는 보통 10분에서 길면 하루가 걸립니다. 연결이 끝나면 Pages 화면에서 Enforce HTTPS 를 체크하세요. 주소창에 자물쇠가 생겨 손님이 안심합니다.

굳이 안 사도 됩니다. 광고에서는 대부분 링크를 눌러서 들어오기 때문에 주소 모양이 매출을 좌우하지는 않습니다. 명함이나 간판에 적을 일이 많다면 그때 사세요.
